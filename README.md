# Автотест: создание заказа и получение заказа по треку

Автотест для API Яндекс.Самоката. Проверяет сценарий:
1. Клиент создаёт заказ.
2. По треку заказа можно получить данные заказа.
3. Код ответа на получение заказа равен 200.

## Требования

- Python 3.8+
- Зависимости из `requirements.txt`




## Логика теста

Тест `test_get_order_by_track_returns_200` проверяет конечное состояние системы:

1. Создаётся заказ (подготовка).
2. Сохраняется трек заказа (подготовка).
3. Заказ запрашивается по треку (подготовка).
4. Проверяется код ответа — `200` (единственная проверка).

В тесте один `assert`, он последний. Шаги до него — подготовка данных,
а не проверки.




## Работа с базой данных

SQL-запросы к заданиям 1 и 2 — в файле [`database_tasks.sql`](database_tasks.sql).

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка перед запуском

1. Откройте `configuration.py` и замените `URL_SERVICE` на адрес вашего тестового стенда.
2. Проверьте, что в `data.py` поля `order_body` соответствуют актуальному API стенда
   (названия полей, значения `metroStation`, допустимые значения `color`).

## Запуск

Все тесты:

```bash
pytest
```

С подробным выводом:

```bash
pytest -v
```

## Примечания

- Логи бэкенда лежат в файле `/var/www/backend/logs/error.log`.
  Если тест падает, начните с этого файла — там будут ошибки сервера.
- Если создание заказа возвращает код, отличный от 201 (например, 200), поправьте
  ожидание в тесте в соответствии с фактическим контрактом API.
